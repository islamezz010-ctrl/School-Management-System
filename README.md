# SchoolDash

A full-stack Next.js school management dashboard inspired by the supplied SchoolLama screenshots.

## Demo Accounts

- Admin: `adam@school.test` / `admin123`
- Teacher: `trevor@school.test` / `teacher123`
- Student: `stella@school.test` / `student123`

## Stack

- Next.js App Router
- JSON files as the data layer
- shadcn-style components
- Radix UI primitives
- TanStack Table
- Recharts
- Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
